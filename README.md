# README.md

# GoalFlow

Система управления задачами и временем для одного пользователя.  
Связывает задачи с целями, ведёт учёт времени прямо в задаче, хранит данные локально.

## Идея

Большинство таск-менеджеров либо слишком простые (плоские списки без связи с целями), либо слишком сложные (десятки полей и вложенных баз). Отдельная боль — учёт времени: нужно переключаться в другое приложение, помнить о таймере, потом сопоставлять записи с задачами.

GoalFlow решает три задачи:

1. **Связь задач с целями.** Жёсткая иерархия Goal → Project → Task. Всегда видно, зачем делаешь задачу.
2. **Учёт времени без фрикшна.** Таймер start/stop прямо в задаче. Никаких отдельных приложений.
3. **Локальность.** Данные — на вашем сервере, в JSON-файлах. Никакого облака.

Приложение минималистичное, keyboard-first, без AI и без авторизации (личный проект).

## Возможности

- **Иерархия** Goal → Project → Task с прогрессом по количеству выполненных задач.
- **Inbox** для задач без проекта.
- **Таймер** на задаче: старт / стоп, только один активный, авто-стоп через 8 часов.
- **Ручной ввод времени** — для случаев, когда таймер забыли.
- **Агрегация времени** на задаче: всего / сегодня / активный таймер.
- **Плоские теги** с autocomplete.
- **Пресеты:** Inbox, Сегодня, Просрочено, В работе, Выполнено, Потрачено > 4 ч, Без времени.
- **Popover с фильтрами:** статус, проект, цель, теги, дедлайн, потраченное время.
- **Поиск** по названию и описанию.
- **Хоткеи** и **command palette** (`Cmd+K`).
- **Quick capture** (`N`) — быстрое создание задачи.
- **Экспорт / импорт** всех данных в один JSON-файл.
- **Локальное хранение** в JSON-файлах на сервере.

## Как устроено

```
┌─────────────────────┐
│  Angular SPA        │
│  (браузер)          │
└──────────┬──────────┘
           │ HTTP /api
           ▼
┌─────────────────────┐
│  Node.js + Express  │
│  REST API           │
└──────────┬──────────┘
           │ fs
           ▼
┌─────────────────────┐
│  JSON-файлы         │
│  data/*.json        │
└─────────────────────┘
```

- Один процесс Node.js отдаёт API и работает с файлами.
- Один пользователь, без авторизации.
- Клиент общается с сервером по REST.
- В dev-режиме Angular использует прокси `/api → localhost:3000`.

### Модель данных

**Goal** — цель верхнего уровня.

```json
{
  "id": "uuid",
  "title": "Запустить продукт до марта",
  "description": "",
  "status": "active",
  "order": 0,
  "createdAt": "ISO",
  "updatedAt": "ISO"
}
```

**Project** — проект внутри цели.

```json
{
  "id": "uuid",
  "goalId": "uuid",
  "title": "MVP лендинга",
  "description": "",
  "status": "active",
  "order": 0,
  "createdAt": "ISO",
  "updatedAt": "ISO"
}
```

**Task** — задача внутри проекта или Inbox.

```json
{
  "id": "uuid",
  "title": "Написать текст hero",
  "status": "todo",
  "projectId": "uuid | null",
  "description": "",
  "priority": "medium | low | high | null",
  "dueDate": "ISO | null",
  "estimateMinutes": 120,
  "tags": ["текст", "лендинг"],
  "createdAt": "ISO",
  "updatedAt": "ISO",
  "completedAt": "ISO | null"
}
```

`projectId = null` означает, что задача в Inbox.

**TimeEntry** — запись о времени.

```json
{
  "id": "uuid",
  "taskId": "uuid",
  "startTime": "ISO",
  "endTime": "ISO | null",
  "durationMinutes": 120,
  "source": "timer | manual",
  "truncated": false,
  "createdAt": "ISO"
}
```

Активный таймер — это запись с `endTime = null`. Одновременно может быть только одна.

### Логика таймера

1. **Старт.** Если уже есть активный таймер — он останавливается. Создаётся новая запись с `endTime = null`.
2. **Стоп.** Заполняется `endTime`, считается `durationMinutes`.
3. **Лимит.** Если сессия идёт больше 8 часов — сервер обрезает её до 8 и ставит флаг `truncated = true`. Пользователю показывается toast.
4. **Ручной ввод.** Создаёт запись с `source = manual`, длительность 1–480 минут.

## Локальное развёртывание

### Требования

- Node.js 20+
- npm 10+

### Шаги

**1. Клонировать репозиторий**

```bash
git clone <repo-url> goalflow
cd goalflow
```

**2. Запустить сервер**

```bash
cd server
npm install
npm run dev
```

Сервер поднимется на `http://localhost:3000`.  
Папка `data/` и файлы `goals.json`, `projects.json`, `tasks.json`, `timeEntries.json`, `settings.json` создадутся автоматически при первом запуске.

Проверка:

```bash
curl http://localhost:3000/api/health
# {"ok":true,"time":"..."}
```

**3. Запустить клиент (в новом терминале)**

```bash
cd client
npm install
npm start
```

Клиент поднимется на `http://localhost:4200`.  
Прокси `proxy.conf.json` перенаправляет `/api` на `localhost:3000`, поэтому CORS не мешает.

**4. Открыть в браузере**

```
http://localhost:4200
```

### Production-сборка (опционально)

```bash
# Сборка клиента
cd client
npm run build
# результат: client/dist/goalflow/browser/

# Сборка сервера
cd ../server
npm run build
npm start
```

Статику Angular можно отдать тем же Express-сервером или через nginx — по вкусу.

### Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3000` | Порт сервера |
| `DATA_DIR` | `./data` | Папка для JSON-файлов |

## Использование

### Создание цели

1. В сайдбаре нажмите `+` рядом с разделом «Цели».
2. Введите название, при желании — описание.
3. Сохранить.

### Создание проекта

1. Разверните нужную цель в сайдбаре.
2. Нажмите «+ проект».
3. Введите название и сохраните.

### Создание задачи

Вариант 1 — через быстрый ввод:

1. Нажмите `N`.
2. Введите название.
3. Опционально выберите проект.
4. `Enter`.

Вариант 2 — из контекста проекта:

1. Выберите проект в сайдбаре.
2. Нажмите «+ Задача» в верхней панели.
3. Задача создастся в этом проекте.

Задача без проекта попадает в **Inbox**.

### Учёт времени

**Таймер:**

1. На строке задачи нажмите `▶`.
2. Кнопка станет `■`, в верхней панели появится индикатор активного таймера.
3. Нажмите `■` для остановки.

Особенности:

- Одновременно может идти только один таймер. Запуск нового автоматически останавливает предыдущий.
- Если таймер идёт дольше 8 часов, сервер обрежет его до 8 и покажет уведомление.

**Ручной ввод:**

1. Откройте карточку задачи (двойной клик или `E`).
2. В секции «Время» укажите минуты и дату.
3. Нажмите «+ Время».

### Фильтрация

- **Пресеты** — в сайдбаре: Inbox, Сегодня, Просрочено, В работе, Выполнено, Потрачено > 4 ч, Без времени.
- **Расширенные фильтры** — кнопка «Фильтры» в верхней панели. Доступны статус, проект, цель, теги, диапазон дедлайнов и потраченного времени.
- **Поиск** — строка в верхней панели или `/`.

### Экспорт и импорт

- **Экспорт:** в сайдбаре → «Экспорт». Скачается `goalflow-backup-YYYY-MM-DD.json`.
- **Импорт:** в сайдбаре → «Импорт» → выберите JSON-файл. Данные полностью заменятся.

Экспорт — единственный способ сделать резервную копию. Делайте его регулярно.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `N` | Новая задача (quick capture) |
| `Cmd+K` / `Ctrl+K` | Command palette |
| `/` | Фокус в поиск |
| `Space` | Старт/стоп таймера на выбранной задаче |
| `E` | Открыть карточку выбранной задачи |
| `G`, затем `G` | Перейти к Inbox |
| `G`, затем `P` | Перейти к «В работе» |
| `G`, затем `T` | Перейти к «Сегодня» |
| `Esc` | Закрыть модалку |

Хоткеи не срабатывают, когда фокус в поле ввода.

## API

Базовый путь: `/api`. Формат: JSON. Аутентификация отсутствует.

### Goals

| Метод | Путь | Описание |
|---|---|---|
| GET | `/goals` | Список целей с прогрессом |
| POST | `/goals` | Создать |
| PUT | `/goals/:id` | Обновить |
| DELETE | `/goals/:id` | Удалить (каскадно) |

### Projects

| Метод | Путь | Описание |
|---|---|---|
| GET | `/projects` | Список проектов |
| POST | `/projects` | Создать |
| PUT | `/projects/:id` | Обновить |
| DELETE | `/projects/:id` | Удалить (каскадно) |

### Tasks

| Метод | Путь | Описание |
|---|---|---|
| GET | `/tasks` | Список задач |
| GET | `/tasks/:id` | Одна задача |
| POST | `/tasks` | Создать |
| PUT | `/tasks/:id` | Обновить |
| DELETE | `/tasks/:id` | Удалить |

### Time tracking

| Метод | Путь | Описание |
|---|---|---|
| POST | `/tasks/:id/timer/start` | Старт таймера |
| POST | `/tasks/:id/timer/stop` | Стоп таймера |
| POST | `/tasks/:id/time/manual` | Ручной ввод |
| GET | `/tasks/:id/time` | Время задачи |
| GET | `/timer/active` | Активный таймер |

### Tags

| Метод | Путь | Описание |
|---|---|---|
| GET | `/tags` | Уникальные теги |

### Export / Import

| Метод | Путь | Описание |
|---|---|---|
| GET | `/export` | Полный экспорт |
| POST | `/import` | Полный импорт |

### Примеры

```bash
# Создать цель
curl -X POST http://localhost:3000/api/goals \
  -H "Content-Type: application/json" \
  -d '{"title":"Запустить продукт до марта"}'

# Создать проект
curl -X POST http://localhost:3000/api/projects \
  -H "Content-Type: application/json" \
  -d '{"goalId":"<GOAL_ID>","title":"MVP лендинга"}'

# Создать задачу
curl -X POST http://localhost:3000/api/tasks \
  -H "Content-Type: application/json" \
  -d '{"title":"Написать текст hero","projectId":"<PROJECT_ID>","tags":["лендинг"]}'

# Старт/стоп таймера
curl -X POST http://localhost:3000/api/tasks/<TASK_ID>/timer/start
curl -X POST http://localhost:3000/api/tasks/<TASK_ID>/timer/stop

# Ручной ввод
curl -X POST http://localhost:3000/api/tasks/<TASK_ID>/time/manual \
  -H "Content-Type: application/json" \
  -d '{"durationMinutes":90,"date":"2026-01-05"}'

# Экспорт
curl http://localhost:3000/api/export -o backup.json
```

## Данные и бэкап

### Файлы

| Файл | Содержимое |
|---|---|
| `server/data/goals.json` | Цели |
| `server/data/projects.json` | Проекты |
| `server/data/tasks.json` | Задачи |
| `server/data/timeEntries.json` | Записи времени |
| `server/data/settings.json` | Настройки |

### Надёжность

- Запись атомарная: сначала пишется `.tmp`-файл, затем `rename`.
- Запись сериализуется через очередь — параллельные мутации одного файла не пересекаются.
- При старте сервер проверяет активный таймер и, если он старше 8 часов, обрезает его.

### Бэкап

**Вручную:** сайдбар → «Экспорт». Сохраните JSON куда-нибудь в надёжное место.

**Автоматически:** можно настроить cron-скрипт, который копирует папку `server/data/` в `server/backups/`:

```bash
# Каждый день в 23:00
0 23 * * * cp -r /path/to/goalflow/server/data /path/to/goalflow/server/backups/$(date +\%F)
```

### Восстановление

Сайдбар → «Импорт» → выберите JSON. Текущие данные полностью заменятся.

## Ограничения

Осознанные упрощения в текущей версии:

- Нет авторизации. Приложение для одного пользователя.
- Нет синхронизации между устройствами. Доступ к серверу — через LAN, VPN или localhost.
- Нет AI-функций.
- Нет Kanban и Calendar.
- Нет сохранённых видов и конструктора фильтров.
- Нет иерархических тегов.
- Нет паузы таймера (только start / stop).
- Нет уведомлений и напоминаний.
- Нет мобильной версии.
